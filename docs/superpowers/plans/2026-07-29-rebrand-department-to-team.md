> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename `Department` model to `Team`, convert `SupervisorProfile.field` string to FK `teamId`, and update all code/UI references.

**Architecture:** Hybrid approach — codemod-assisted bulk rename + manual fixups for edge cases, organized into phased commits. Prisma handles table/column renames via `migrate dev`.

**Tech Stack:** Next.js 16.2, Prisma 7.8, PostgreSQL, Zod 4.4, TanStack React Query

## Global Constraints

- All Prisma model/field renames must go through `prisma migrate dev --name rebrand_department_to_team`
- `SupervisorProfile.field` → `teamId String?` with FK to Team; existing supervisors default to UMUM team
- Document template variable `"bidang"` → `"team"`
- UI labels: "Bidang", "Divisi", "Departemen" → "Team"
- Seed 12 teams: KEJAR, HALIS, GADIS, CAPUNG, INTANT, HUMAS, SE2026, Pengolahan, D'Stik, PEK, KTIP, UMUM

### Task 3: Codemod — Bulk Code Rename

**Files:** All non-generated `.ts`, `.tsx` files (except schema + templates)

**Approach:** Use a sed/pwsh script to bulk-replace identifiers, then manual fixups for edge cases.

- [ ] **Step 1: Create codemod script**

Run a PowerShell script to perform bulk renames on source files, excluding generated and migration files:

```powershell
$files = Get-ChildItem -Recurse -Include "*.ts", "*.tsx" -Exclude "*.generated.*" |
  Where-Object { $_.FullName -notmatch '\\node_modules\\' -and $_.FullName -notmatch '\\prisma\\migrations\\' -and $_.FullName -notmatch '\\generated\\' }

foreach ($file in $files) {
  $content = Get-Content -Raw $file.FullName

  # Pattern 1: departmentId -> teamId (field names, variable names)
  $content = $content -replace '(?<![\w-])departmentId(?![\w-])', 'teamId'
  # Pattern 2: Department -> Team (model/type names, capitalized)
  $content = $content -replace '(?<![\w-])Department(?![\w-])', 'Team'
  # Pattern 3: department -> team (variable/property names, but NOT "department" in strings/labels)
  # Only replace identifier-pattern uses
  $content = $content -replace '(?<![\w-])department(?![\w-])', 'team'

  Set-Content -NoNewline -Path $file.FullName -Value $content
}
```

This handles:
- `departmentId` → `teamId`
- `Department` → `Team` (model, type names)
- `department` → `team` (variables, properties, includes)
- `departmentName` → `teamName`
- `departments` → `teams`
- `DeptDistribution` → `TeamDistribution`

- [ ] **Step 2: Run the codemod**

```bash

```
